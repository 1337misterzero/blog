# zero

Personal Hugo blog.

## Setup

This repository uses Hugo and the PaperMod theme.

Replace `YOURUSERNAME` in `config.toml` with your GitHub username.

The theme is expected as a Git submodule:

```bash
git submodule add https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod
```

Then push the repository to GitHub and enable **GitHub Pages → GitHub Actions**.
